# AdQuick

> AdQuick is an intelligence and marketplace platform for out-of-home (OOH) advertising. Advertisers plan, buy, execute, and measure billboard, transit, street-furniture, and programmatic digital-out-of-home (DOOH) campaigns across 1,500+ media owners covering close to 100% of US OOH supply. AdQuick exposes a partner REST API and a hosted Model Context Protocol (MCP) server for AI agents.

Generated by the API Evangelist enrichment pipeline (method: generated) from apis.yml and repository artifacts. Some source pages are Cloudflare-protected; the MCP/OAuth surface was confirmed against live discovery metadata.

## APIs

- [AdQuick Partner API](https://docs.adquick.com/): REST API for planning guaranteed and auction OOH campaigns, insertion orders, creatives, and delivery reporting. Base URL https://api.adquick.com. Auth: X-PARTNER-TOKEN header. Errors: RFC 9457 problem+json.
- [AdQuick MCP Server](https://www.adquick.com/mcp/usage-documentation): Hosted Model Context Protocol server (Streamable HTTP, OAuth 2.0 + PKCE) at https://www.adquick.com/mcp exposing 39 tools across inventory discovery, campaign management, analytics, exports, programmatic DSP, and scheduling.
